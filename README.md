# Tembel Hesap Makinesi Supreme

Bu, evrenin en tembel, en absürt, en ciddiyetle yaramaz hesap makinesidir.

## Ne Yapar?

Hiçbir şey. Ama çok ciddi bir şekilde hiçbir şey yapmaz.

İki sayı verirsin, o da "Yorgunum kardeşim, sonra bakarım" der. Ama aslında hesaplar. Gizli hesaplar.

## Kullanım

```bash
python tembel_hesap.py
```

Sonra sayıları gir. Makine düşünecek. Çok düşünecek. Belki uyuyacak.

## Neden Var?

Çünkü biri sordu "neden olmasın?" diye. Cevap yok. Sadece tembellik.

## Özellikler

- Sonsuz yorgunluk modu
- Gizli hesaplama algoritması (şu an açık)
- Türkçe şikayet sistemi
- Hiçbir şey yapmama konusunda dünya rekoru
